Concept

Chess analysis through branching exploration.

Branching game tree

Every different move creates a new branch. Navigate freely between variations — the full history of your exploration is preserved.

Deterministic engine

Same position, same response. Play a different move and Stockfish picks fresh from its top 5 — weighted by score, cached by FEN.

Visual tree panel

See every explored line as a clickable, zoomable tree. Green path shows where you are. Click any node to jump there instantly.

Full control

Set up any position, adjust engine strength from beginner to full power, import PGN games, and save or load positions.

Features

Everything you need to explore the game.

Interactive board

Click to select a piece, click to move. Legal moves are highlighted on the board.

Engine strength slider

Control how strong Stockfish 18 plays — from beginner to full strength. Changes clear the response cache.

Game tree visualization

Pan, zoom, and click nodes to jump to any position. Branch info and the current variation displayed below.

Setup mode

Place pieces freely to create any position. Select from the palette, toggle sides, and start playing.

PGN import

Paste any game from your clipboard and explore it move by move in the branching tree.

Save & load positions

Positions stored as JSON with FEN strings and timestamps. Share files or hand-edit them.

How It Works

Deterministic responses from stochastic selection.

You play a move

New board position identified by FEN string

Cache lookup

Has the engine seen this exact position before?

Cache hit

Same response — you follow the existing branch

Cache miss

Stochastic pick from Stockfish's top 5 — a new branch is born

Get Started

Up and running in under a minute.

Setup

python3 -m venv .venv source .venv/bin/activate pip install -r requirements.txt python branChess.py

Requires Python 3. Stockfish binary is included — no extra downloads needed.
